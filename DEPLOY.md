# Публикация MIXLAB

## GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите содержимое папки `mixlab_site` в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите публикацию из ветки `main` и каталога `/ (root)`.
5. После публикации GitHub выдаст публичный адрес сайта.

Сайт не требует сборки: достаточно HTML, CSS и JavaScript-файлов.
