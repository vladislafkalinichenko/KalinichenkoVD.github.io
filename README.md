# MIXLAB — сайт о сведении музыки

MIXLAB — практический сайт о сведении музыки: теория, таблицы, полезные ссылки, чек-лист и интерактивные инструменты.

## Разделы
- Главная
- О MIXLAB
- Процесс сведения
- Эквализация
- Динамика
- Пространство
- Стерео
- Референсы
- Глоссарий
- Чек-лист
- Веб-виджеты
- Сервисы

## Сервисы
Поиск по сайту, гостевая книга, форум, новости, статистика, рейтинг, LUFS-калькулятор, компрессор-ассистент, стерео-чекер, BPM / такты / delay и планировщик сведения.

## Запуск
Откройте `index.html` в браузере или запустите локальный HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000/`.
