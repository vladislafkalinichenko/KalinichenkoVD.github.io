# Требования лабораторных работ

Основание: «Методические указания для лабораторной 1.docx» и «Лаб_практикум_Веб-технологииИТ.doc», предоставленные преподавателем.

## Первая работа и замечания

| Замечание | Реализация |
|---|---|
| Мелкое незаметное меню | Контрастная синяя панель, светлый текст 16–17 пикселей, выделение активного раздела |
| Меню переносится | Один ряд без `flex-wrap`; интервалы уменьшаются. На узком телефоне доступна горизонтальная прокрутка без уменьшения текста до нечитаемого размера |
| Пункты XML, БД, RSS | Добавлены в общее меню, ведут на отдельные страницы |
| Новости в БД и видимый результат | PHP + PDO SQLite/MySQL, форма администратора и лента; статический режим использует IndexedDB с явной пометкой локальных записей. Общей онлайн-БД на Pages нет |
| Поиск везде | Одинаковая форма под меню на всех 30 HTML-страницах, поиск по полному тексту |
| Погода для посетителей из России | Браузер получает данные с адреса самого сайта. Обновление внешнего источника выполняется на GitHub Actions; проверка из РФ не проводилась |
| Наглядные информеры | Крупные карточки погоды, курсов, новостей, статистики и рейтинга; видны даты и состояния ошибок |
| Русский язык | Переписаны статьи, интерфейс, результаты расчётов и названия страниц. MIXLAB сохранён как имя проекта; XML, RSS и LUFS — названия форматов/единиц |
| Повтор сервисов | Погода и курсы только на главной; новости имеют краткую сводку и полную ленту. Статистика и рейтинг доступны через управление, музыкальные инструменты — через сервисы |
| Сложные термины | Тексты объясняют задачи через голос, инструменты, громкость и эхо; специальным словам дано пояснение |

Требования первой работы: не менее 10 HTML-страниц; графика, таблицы, метаданные, авторство, навигация, внутренние ссылки, коллекция внешних ссылок, поиск, обязательные сервисы и пять дополнительных оригинальных сервисов. Сайт содержит 30 страниц, локальную SVG-иллюстрацию и пять музыкальных инструментов. Отдельное подтверждение нужны для регистрации/индексации поисковой системой и внешней W3C-валидации.

Рейтинг сайта как оценка посетителя не тождественен рейтингу поисковой системы. Учебные локальные счётчики и обсуждения также не заменяют общую серверную статистику/форум. В интерфейсе используются личная оценка и история просмотров. Технические ограничения описаны в документации.

## Что учтено для будущих работ

Подробности запуска и демонстрации — в LAB2.md. На GitHub Pages опубликован результат преобразования; PHP выполняется на PHP-хостинге или локально.
3. **PHP и БД:** приложение с 3–5 типами запросов, визуализацией, агрегированием и при необходимости графиками. Подготовлено хранение новостей и MySQL-схема. Не объявляется выполненной лабораторной № 3.
4. **Обмен данными:** RSS/XML, выгрузка данных из БД, обработка/объединение разных источников. У новостей есть стабильный идентификатор, заголовок, текст, дата, источник, адрес источника и категория. Импорт внешнего RSS пока не реализован.

В общей методичке также есть более поздний раздел о документации. Он не относится к текущей доработке первой работы.
