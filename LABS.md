## Работа 1

- 31 HTML-страница, русская навигация, текст разных размеров и цветов, таблицы, локальные иллюстрации, авторство, метаданные и внутренние якоря.
- Поиск по полному тексту сайта под меню каждой страницы; коллекция тематических внешних ссылок.
- Информеры погоды и курсов с одного домена; обновление каждые три часа на alwaysdata.
- Общая серверная лента новостей и добавление через вход администратора.
- Общие гостевая книга, темы форума и ответы: записи доступны другим посетителям.
- Модерация сообщений: скрытие/восстановление, запрещённые выражения, ограничения публикаций с выбранных подключений.
- Серверная статистика просмотров, уникальных посетителей, текущего дня и отдельных страниц. День определяется по московскому времени. Старая браузерная статистика не подмешивается в общие результаты.
- Рейтинг: средняя оценка посетителей и число голосов. Один сохраняемый голос на cookie браузера; его можно изменить или удалить. Это пользовательский рейтинг, не позиция в поисковой выдаче.
- Пять дополнительных оригинальных инструментов: расчёт задержки по темпу, оценка громкости, расчёт компрессии, настройка панорамы и планировщик сведения.
- Поисковый баннер Google на странице полезных ссылок; все музыкальные инструменты открываются по отдельным адресам.
- Бесплатный PHP-хостинг alwaysdata; главная проиндексирована Google (проверено через Search Console 13.10.2026 по московскому времени).
- Все HTML-страницы (31) проверены Nu HTML Checker 26.10.12: 0 ошибок и 0 предупреждений. Итог — `tests/validation/nu-local.json`. Первоначальные ответы внешнего сервиса, включая ограничение частоты запросов, сохранены в `w3c-before-fixes.json`.

## Работа 2

18 записей XML, у каждой 7 полей; схема XSD. PHP читает XML, проверяет схему и выполняет XSLT. Поиск, совместные фильтры по теме и уровню, сортировка по дате/названию/времени чтения в обоих направлениях. Форма работает без JavaScript на https://vlad-mixlab.alwaysdata.net/xml.html .

XMLPad/XMLSpy может открыть файлы и выполнить валидацию/преобразование; работа в самом редакторе здесь не имитируется. Форма отчётности — опубликованная динамическая страница.
