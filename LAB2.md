# Лабораторная № 2: XML, XSL и PHP

## Что сделано

Раздел «XML» открывает каталог «Заметки о сведении». Это авторские тематические публикации MIXLAB, а не заимствованные новости музыкальной индустрии. Даты в XML — даты публикаций каталога, время чтения — ориентир для заметки вместе с материалом по ссылке.

- `data/mixing-news.xml` — **18 объектов `news`**.
- В каждом объекте **7 дочерних тегов**: `title` (заголовок), `date` (дата), `category` (тема), `level` (уровень), `minutes` (минуты чтения), `summary` (текст), `link` (страница сайта). `id` — отдельный уникальный атрибут.
- `data/mixing-news.xsd` — схема: 15–20 объектов, обязательные поля, даты, допустимые темы и уровни, положительное время чтения, внутренние ссылки и уникальные XML ID.
- `data/mixing-news.xsl` — XSLT 1.0: отбор через XPath, `xsl:sort`, карточки, форма, количество результатов и пустая выборка. Параметры: `q`, `category`, `level`, `sort`, `order`.
- `server/xml_catalog.php` — проверка параметров, DOMDocument, проверка XML по XSD, передача параметров в XSLTProcessor, преобразование XML в HTML. Запрещены внешние сущности, чтение/запись файлов и сети из XSLT; пользовательские параметры не вставляются в XPath.
- `xml.php` — динамическая страница PHP: читает GET-параметры и выполняет XSL-преобразование при каждом запросе. Форма работает **без JavaScript**.
- `xml.html` — общая оболочка и собранная версия для GitHub Pages. На локальном PHP-сервере `server/router.php` направляет этот адрес в `xml.php`; на Apache это делает правило `.htaccess`, если доступен mod_rewrite. На других PHP-хостингах можно открыть `xml.php` напрямую.

## Отбор и сортировка

Фильтры по теме и уровню применяются совместно с поиском по заголовку и тексту. Поиск не различает регистр русского/латинского алфавита и буквы «е»/«ё». Сортировка: дата, название, число минут; для каждого поля доступны возрастание и убывание. При одинаковых значениях сохраняется однозначный порядок по ID. Выбор хранится в адресе страницы; есть сброс и сообщение для пустой выборки.

## Запуск PHP для демонстрации

Требуются PHP 8.1+ и расширения **DOM, libxml, XSL**. База данных для этого раздела не нужна.

Проверка расширений:

```bash
php -m
```

Из корня проекта:

```bash
php -S 127.0.0.1:8000 server/router.php
```

Открыть `http://127.0.0.1:8000/xml.html` или `http://127.0.0.1:8000/xml.php`.

На Windows можно использовать PHP из XAMPP: включить `extension=xsl` в используемом `php.ini` и запускать команду полным путём к `php.exe`. Если запускаешь через Apache, размести папку в его каталоге сайтов и открой `xml.php` по HTTP. Открытие файла двойным щелчком или Live Server из VS Code не запускает PHP.

Демонстрация преподавателю:

1. Показать 18 записей и семь полей в XML.
2. Показать XSD и XSL: XPath-отбор, параметры и `xsl:sort`.
3. Открыть `xml.php`: выбрать «Стерео» + «Продвинутый» — одна запись «Ширина без потери основы».
4. Сбросить фильтры; найти «ГОЛОС» — поиск не зависит от регистра.
5. Отсортировать время чтения по возрастанию: первой будет заметка на 2 минуты.
6. Ввести несуществующее слово — увидеть пустую выборку, затем сбросить.
7. Отключить JavaScript: форма PHP продолжает работать. Это показывает, что отбор выполняет сервер, а не только браузер.

## XMLPad / XMLSpy

Файл в UTF-8, схема указана атрибутом `xsi:noNamespaceSchemaLocation`. Открой `data/mixing-news.xml` в XMLPad или XMLSpy, просмотри дерево `catalog → news`, выполни проверку корректности XML и валидацию по `mixing-news.xsd` из той же папки. Для преобразования выбери `mixing-news.xsl`. Названия команд зависят от установленной версии редактора. Работа в XMLPad здесь не имитировалась: проверка выполнена настоящим PHP/libxml/XSLTProcessor. При необходимости скриншоты редактора нужно сделать после открытия этих файлов на своём компьютере.

## GitHub Pages и PHP — разные способы запуска

GitHub Pages публикует статические файлы и не исполняет PHP. Поэтому `tools/build_xml.php` заранее создаёт HTML **из того же XML через ту же XSL-таблицу и PHP**. В опубликованной версии `assets/catalog.js` фильтрует и сортирует готовые карточки; браузерный XSLTProcessor не нужен. Без JavaScript на Pages доступны все 18 публикаций, но интерактивные фильтры не работают.

GitHub Actions устанавливает PHP/XSL, пересобирает каталог и поисковый индекс, запускает проверки и публикует сайт. После изменения XML нужно выполнить:

```bash
php tools/build_xml.php
python tools/build_search.py
```

**Для требования «PHP-приложение в Интернет» одного GitHub Pages недостаточно.** Исходники и локальный PHP-вариант готовы, но для демонстрации серверной обработки по публичной ссылке нужно разместить этот же проект на хостинге с PHP и XSL. Нельзя выдавать статическую версию за выполняющийся на GitHub сервер PHP.

## Проверки

```bash
python tests/xml_catalog.py
python tools/check_site.py
```

`tests/xml_catalog.py` поднимает реальный PHP-сервер и проверяет схему, количество записей/полей, повторяемость сборки, серверную маршрутизацию, фильтры, шесть вариантов сортировки, пустую выборку, экранирование и недопустимые параметры. При нестандартном расположении PHP можно задать `PHP_BIN`.

Проверка интерактивных фильтров Pages: установить `linkedom` как внешнюю зависимость для тестирования, затем `NODE_PATH=<путь>/node_modules node tests/catalog.cjs`. Зависимость не включается в сайт.
